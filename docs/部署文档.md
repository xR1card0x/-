# 信息雷达站 · 部署文档

本项目为**纯静态前端应用**（原生 HTML/CSS/JS，零依赖、零构建），任何能托管静态文件的环境均可部署。

## 1. 项目结构

```
信息雷达站/
├── index.html            # 应用入口
├── css/style.css         # 样式设计系统
├── js/data.js            # 活动数据模型 + 26 条模拟信息（种子数据）
├── js/app.js             # 应用逻辑（筛选/详情/发布/收藏/日历/通知）
├── docs/
│   ├── 考核题目原文.html  # 题目存档
│   ├── 数据库设计.md
│   └── 部署文档.md
└── README.md
```

## 2. 本地运行

**方式一：直接打开**
双击 `index.html` 即可使用（收藏等数据依赖 localStorage，主流浏览器均支持）。

**方式二：本地静态服务（推荐，地址栏支持 Hash 路由分享）**

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

访问 `http://localhost:8080`。

> 注意：请通过 HTTP 服务或直接打开方式访问，**不要用 file:// 以外的特殊协议**，否则部分浏览器会限制 localStorage 与剪贴板 API。

## 3. GitHub Pages 部署（推荐，零成本）

```bash
# 1. 将仓库推送到 GitHub（本项目远程仓库已配置）
git push origin main

# 2. 在 GitHub 仓库页面：
#    Settings → Pages → Source 选择 "Deploy from a branch"
#    Branch 选择 main / (root) → Save
```

一两分钟后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
后续更新只需 `git push`，Pages 自动重新发布。

## 4. Nginx / 云服务器部署

```nginx
server {
    listen       80;
    server_name  radar.example.com;
    root         /var/www/radar;   # 项目文件所在目录
    index        index.html;

    # 静态资源缓存
    location ~* \.(css|js|svg|png)$ {
        expires 7d;
        add_header Cache-Control "public";
    }
    # index.html 不缓存，保证更新即时生效
    location = /index.html {
        add_header Cache-Control "no-cache";
    }
}
```

部署步骤：将整个目录上传至服务器（`scp -r . root@server:/var/www/radar`），重载 Nginx（`nginx -s reload`）。如需 HTTPS，用 certbot 申请免费证书即可。

## 6. 数据与更新说明

- **种子数据**：全部活动信息在 `js/data.js` 的 `SEED_ACTIVITIES` 数组中。更新活动信息只需修改该文件（如调整 `deadline`、新增 `updates` 更新记录），刷新页面即生效，无需数据库。
- **用户数据**：收藏、报名标记、发布的活动、通知已读、新生模式开关保存在浏览器 `localStorage`（键名见 `js/data.js` 的 `LS_KEYS`），**不同浏览器/设备之间相互独立**；用户可在「我的」页一键清除。接入后端的规划见 `docs/数据库设计.md`。
- **时间敏感项**：活动状态（即将截止/已截止/已结束）基于用户设备当前时间动态计算。演示时如需重置时间背景，修改 `js/data.js` 中的 ISO 时间字符串即可。

## 7. 浏览器兼容

Chrome / Edge / Firefox / Safari 现代版本均可正常使用。用到的主要特性：ES6+、CSS Grid、`localStorage`、Blob 下载（ICS 日历）、Web Share API（移动端，不支持时自动降级为复制文案）。
