# 信息雷达站 · 校园活动与机会
一个面向在校学生（重点考虑新生使用体验）的校园活动与机会聚合站。将学校/学院、学生个人等多来源的活动信息集中扫描、结构化呈现，逐条标注 **类型、状态、可信度、适合对象与新生友好度**，帮助同学更低成本地发现、判断、参与或发布活动。

> 本项目为《计算机协会软件部 2026 年秋季纳新第二轮考核》作品，数据为题目提供的模拟信息，不代表学校真实通知。题目原文存档见 `docs/考核题目原文.html`。

## 解决的问题
- 多来源信息散落各处（通知群、公众号、朋友圈），**质量与可信度参差不齐**，新生难以判断；
- 活动关键要素（截止时间、地点、费用、报名方式）经常缺失，容易被忽略或误信；
- 学生自发活动缺少进入正规信息流的渠道，而高风险信息（兼职推广、广告）又容易混入其中。

核心功能
| 功能 | 说明 |
| --- | --- |
| 多维筛选与搜索 | 7 种活动类型 / 7 种状态 / 4 种适合对象 / 3 级新生友好度 / 3 类信息来源，全文搜索，智能排序（今日活动 → 即将截止 → 有更新优先） |
| 详情行动卡 | 活动时间、报名截止（**实时倒计时**）、地点（线上/线下）、报名要求、适合对象、预计投入、费用、状态、来源可信度（盾牌标识）、联系方式逐项呈现 |
| 学生自主发布 | 完整表单（标题≤50字、类型、起止时间、地点、适合对象、免费/收费/AA、联系方式、来源说明≤100字等），发布后带「学生个人发布」标识进入正常信息流 |
| 收藏与报名跟踪 | 一键收藏、标记已报名，全部保存在本地（刷新不丢失），「我的」页统一管理 |
| 日历集成 | 一键生成 `.ics` 文件导入系统日历（活动时间未注明时禁用，不编造时间） |
| 通知中心 | 补充更新推送、收藏/已报名活动的截止前提醒（48小时内）、今日开始提醒、高风险关注提醒 |
| 分享 | Web Share API / 复制文案，链接直达活动详情 |
新的
1. **新生模式**：一键切换后仅展示「新生推荐」内容并隐藏高风险信息，针对新生信息甄别能力弱的核心痛点。
2. **缺信预警（信息完整度提示）**：对每条活动自动检测"地点/费用/截止/联系方式"等 8 类关键字段是否未注明，在详情页集中提示"哪些信息需要先向发布方核实"，**不擅自补全、不编造**。
3. **风险识别提示**：对高风险信息（如"添加私人微信日结兼职"）给出具体风险特征清单与防骗提示，把"不可信"转变成"可识别"。
4. **更新时间线**：编号 09 / 20 等补充通知合并进原活动（01 / 03）的更新记录，避免新旧信息互相矛盾、错过变更。
